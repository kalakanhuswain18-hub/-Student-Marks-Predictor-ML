# Student Marks Predictor (ML)

This project uses Linear Regression to predict student marks based on:
- Study Hours
- Revision Hours
- Sleep (optional)

## Tech Used
- Python
- Pandas
- Scikit-learn

## Features
- Single & Multiple input prediction
- CSV dataset usage
- User input based prediction

## How to Run
1. Install libraries: pip install pandas scikit-learn
2. Run the notebook
3. Enter input values

## Example
Input:
Study Hours = 6
Revision = 2

Output:
72.28 Marks
